User Guide and Knowledge Base for Smart Restaurant Solution.
دليل المستخدم وقاعدة المعرفة لحل المطعم الذكي.
Getting Started البدء
Access the complete documentation hub to explore system setup, service structure, and initial configurations across all modules.
اطَّلع على مركز التوثيق الكامل لاستكشاف إعداد النظام وهيكل الخدمة والتكوينات الأولية عبر جميع الوحدات.
Cloud POS نقطة البيع السحابية
A point-of-sale application enabling real-time transaction handling, cashier control, payment integration, and shift reporting.
تطبيق نقطة بيع يُتيح معالجة المعاملات في الوقت الفعلي، والتحكم في الكاشير، وتكامل الدفع، وتقارير الوردية.
Cloud Administration الإدارة السحابية
A centralized web portal for configuring system roles, user permissions, device registration, and application-wide settings.
بوابة ويب مركزية لتكوين أدوار النظام وأذونات المستخدمين وتسجيل الأجهزة والإعدادات العامة للتطبيق.
Smart Kiosk الكشك الذكي
A self-service solution designed for customer-side ordering, supporting real-time sync with menus, payments, and kitchen operations.
حل خدمة ذاتية مصمَّم لطلبات العملاء، يدعم المزامنة الفورية مع القوائم والمدفوعات وعمليات المطبخ.
Inventory Management إدارة المخزون
Monitor stock levels across multiple branches with tracking, reorder rules, and automatic inventory adjustments.
راقب مستويات المخزون عبر فروع متعددة مع التتبع وقواعد إعادة الطلب والتعديلات التلقائية للمخزون.
Smart Menu القائمة الذكية
A dynamic menu management tool allowing product, category, modifier, and pricing configuration synced with all sales channels.
أداة إدارة قوائم ديناميكية تُتيح تكوين المنتجات والفئات والمعدِّلات والتسعير بالتزامن مع جميع قنوات البيع.
Smart Kitchen Application تطبيق المطبخ الذكي
Displays live kitchen orders with task separation, preparation timers, and device-based station assignments for order fulfillment.
يعرض طلبات المطبخ الحية مع فصل المهام ومؤقتات التحضير وتعيينات المحطات المستندة إلى الأجهزة لتنفيذ الطلبات.
Smart WhatsApp واتساب الذكي
Integrates WhatsApp to automate order notifications, delivery updates, and chat-based support directly with end users.
يدمج واتساب لأتمتة إشعارات الطلبات وتحديثات التوصيل والدعم عبر المحادثة مباشرةً مع المستخدمين النهائيين.
Smart Waiter النادل الذكي
A waiter-assist interface providing table-side ordering, live updates, and communication tools synchronized with the main POS system.
واجهة مساعدة النادل توفر الطلب من جانب الطاولة والتحديثات الحية وأدوات التواصل المتزامنة مع نظام نقطة البيع الرئيسي.
